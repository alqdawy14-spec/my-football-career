# My Path — Football Career (prototype 0.1)

نسخة أولية قابلة للعب من لعبة مسيرة لاعب كرة قدم، مع تحكم باللمس.

## تشغيل سريع
- افتح `index.html` في متصفح حديث، أو ارفع المجلد على استضافة HTTPS.
- على أندرويد، افتح رابط النسخة في Chrome ثم اختر **إضافة إلى الشاشة الرئيسية**. التثبيت كـ PWA يحتاج استضافة HTTPS حتى يعمل بشكل موثوق.
- التقدم يُحفظ محليًا في المتصفح على نفس الجهاز.

## الموجود الآن
- لاعب واحد قابل للتحكم بعصا لمس افتراضية.
- تمرير وتسديد، خصوم يتحركون نحو الكرة، مرمى واحتساب أهداف.
- تدريب يرفع الإحصائيات، مكافأة بعد المباراة، سجل مسيرة محفوظ محليًا.

## بصراحة عن حدود النسخة
هذه نواة 2D تجريبية وليست لعبة بمستوى PES ولا ملف APK أصليًا. للوصول إلى تطبيق أندرويد أصلي ورسوم 3D نحتاج مرحلة تطوير منفصلة في Godot أو Unity، ثم اختبار وبناء APK/AAB وتوقيعه. لا توجد أندية أو أسماء أو شعارات مرخّصة في هذه النسخة.
